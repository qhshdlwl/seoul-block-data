# seoul-block-data

서울에서 집회·마라톤으로 통제가 예정된 곳을 하루 두 번 정리한 정적 JSON(`events.json`)입니다. 교통 정보 용도입니다.

- 집회: [서울경찰청 오늘의 집회](https://www.smpa.go.kr/user/nd54882.do) 게시 내용 중 일시·장소·신고 인원·관할서 (주최·목적은 원문에도 없고 여기에도 없습니다)
- 마라톤: [서울특별시 광역 교통통제(예정) 마라톤 안내](https://news.seoul.go.kr/culture/)
- 좌표는 대략적인 추정치입니다. 실제 통제는 현장 상황에 따라 달라질 수 있습니다.

이 레포는 자동으로 갱신됩니다. 직접 수정하지 마세요.
